1 Preface
 The SmartVista E-commerce Payment Gateway 1.33: Branding Guide describes how to configure the
 appearance of the SmartVista E-commerce Payment Gateway 1.33 pages that are displayed to
 customers when making online purchases.

 Audience
 This guide is intended for merchants who use SmartVista E-commerce Payment Gateway 1.33 (EPG) to
 process online payments and who want to customize pages for their sites by themselves.

  Sass preprocessor (version 3.5.3 or higher) to be installed. More information is available at the following
  URL: https://sass-lang.com/documentation/file.SASS_REFERENCE.html

3 EPG application settings
 The following application settings must be configured on the Administration > System Settings menu of
 the EPG administrative portal (see the SmartVista E-commerce Payment Gateway Administration Guide
 for more information) to enable customizing pages:

  Parameter                                     Description
  merchantStaticHost                            Host on which to store the static pages.

  merchantStaticHostPort                        Port on the host that stores the static pages. The default value is
                                                0.

  merchantStaticHostLogin                       Login to connect to the host that stores the static pages.
  merchantStaticHostPassword                    Password to connect to the host that stores the static pages.

  staticDir                                     Directory on the host that stores the static pages.
  defaultStaticDir                              Default directory on the host that stores the static pages. The
                                                default value is /.
                                                This field is optional. If you need to redefine the default value, add
                                                it by clicking Create on the System Settings page and specifying
                                                the new default directory.

  defaultStaticFile                             Name of the default file that contains the static pages. The default
                                                value is testMerchantStatic.zip.
                                                This field is optional. If you need to redefine the default value, add
                                                it by clicking Create on the System Settings page and specifying
                                                the new default file.

  merchantStaticUploadEnabled                   Flag that enables merchants to upload customized static pages.
                                                The default value is false.
                                                This field is optional. If you need to redefine the default value,
                                                change it by clicking Create on the System Settings page.

 The account must have the CUSTOMIZE_PAYMENT_PAGE permission with the VIEW action.

4 Configuring common settings for pages
 You can modify settings that apply to all payment pages at once. All these settings are configured in the
 bpc.scss file. To configure the common payment page settings:
 1. Open the /sass/bpc.scss file.
 2. Configure the relevant parameters:
   Fonts used

    Parameter                                   Description
    font-family                                 Font on all pages of the site. Configure several font names so
                                                that if a browser does not support the first font, it can use
                                                another font specified. To configure the parameter, specify for
                                                the font-family parameter values separated by commas, for
                                                example:
                                                   $font-family: "Custom font", "Helvetica Neue",
                                                   Helvetica, Arial, sans-serif;

    font-face                                   The font-face rule is used to configure font support for each
                                                browser and operating system. Custom fonts must be placed in
                                                the fonts folder.
                                                For normal font specify font-weight: 400:
                                                   @font-face {
                                                   font-family: 'MyWebFont';
                                                   src: url('../fonts/webfont.eot'); / IE9 Compat

5 Customizing the card data entry page
 The following elements can be customized on the page where the customer enters the payment card
 information:
 · The header, which typically contains a merchant logo ❶ and headings of different levels providing
   information such as the order number, description, and the remaining session time
 · Elements of the page body such as the formatting of card expiration fields ❷ and the main control
   elements (buttons, check boxes) ❸
 · The footer, which typically contains the logos of the 3-D Secure systems supported by the payment
   gateway ❹

8 Uploading customized pages
 Upload the archive with customized pages using the EPG administrative portal:
 1. Click Static > Static Upload and Download.
 2. In the Upload static section for the ZIP-archive field, click Choose file, and specify the path to the
     folder that contains the statics archive with the customized pages.
 3. Click Upload.
 EPG deploys the pages from the archive on the server specified in the system settings.
 For more information, see “Static Content Customization” in the SmartVista E-commerce Payment
 Gateway User Guide.
